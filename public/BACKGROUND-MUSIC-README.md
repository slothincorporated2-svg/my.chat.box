# Background Music

To add background music to your chat app:

1. Find a royalty-free music file (MP3 or OGG format)
2. Name it `background-music.mp3` or `background-music.ogg`
3. Place it in this `public/` folder
4. The app will automatically play it on loop

## Recommended Music Sources:
- Free Music Archive (freemusicarchive.org)
- Incompetech (incompetech.com) - Kevin MacLeod
- YouTube Audio Library
- Bensound.com

For sci-fi theme, search for:
- Ambient space music
- Electronic background tracks
- Cinematic atmosphere
- Lo-fi beats

Keep file size under 5MB for fast loading.
